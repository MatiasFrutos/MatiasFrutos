## Acerca de mí

Desarrollador Full Stack con formación técnica en electrónica, diagnóstico, mantenimiento y soporte. Llevé esa experiencia práctica al software: herramientas internas, paneles administrativos, utilidades de escritorio, automatizaciones y aplicaciones web.

Mi enfoque actual está en aplicaciones nativas para Linux con **Rust y Tauri**, desarrollo backend y automatización con IA local. Priorizo soluciones claras, mantenibles y orientadas a resolver problemas reales.

## Áreas de trabajo

- **Backend y APIs:** servicios REST, lógica de negocio y arquitectura del lado del servidor.
- **Aplicaciones de escritorio:** Rust + Tauri para Linux (AppImage, .deb, .rpm); Electron, Python y C# para herramientas internas.
- **Automatización:** scripts y procesos que eliminan trabajo operativo repetitivo.
- **Software de negocio:** sistemas administrativos, paneles internos y modelado de datos.
- **IA aplicada:** asistentes y flujos con modelos locales.
